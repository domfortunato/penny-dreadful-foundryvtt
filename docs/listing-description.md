# Module Description

Dom's description of the Penny Dreadful mini-game, written by him for the
foundryvtt.com package listing (Foundry's AI policy §4.5 requires a
human-written description). `module.json`'s `description` is the same text as
HTML. Paste the text below into the listing form.

---

Penny Dreadful is a truly minimalist TTRPG system with no character sheets and a very simple resolution mechanic: each player starts with one penny. When they need to make a save, the Director gives them a Difficulty Level (DL) and they flip their pennies. Heads count 1 and tails count 0. If the number of heads meets or beats the DL, they pass the save. If not, they might still succeed in their action, but their doom comes closer, and they add another penny to their hand. The DL is variable, but the maximum is 5. If a player holds ten pennies and fails a save, it's the end of their rope.

The Penny Dreadful mini-game provides a fully automated scoreboard to run Penny Dreadful inside an existing Foundry world, with any system. The Dice So Nice module is recommended, because nothing builds tension like flipping a handful of pennies to decide your fate.

Daniel Fitzpatrick created the Penny Dreadful game rules under CC BY-SA 4.0, and he is not involved in this project. You can view and download his Penny Dreadful rules and adventures at [baphelon.itch.io/penny-dreadful](https://baphelon.itch.io/penny-dreadful).
